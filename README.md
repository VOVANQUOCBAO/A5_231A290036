# Lab A5 - Chuyển màn hình và truyền dữ liệu bằng Intent

**Họ tên:** Võ Văn Quốc Bảo

**MSSV:** 231A290036

**Học phần:** INT4211 - Lập trình trên các thiết bị di động

## Nội dung

- Truyền thông tin liên hệ giữa MainActivity và DetailActivity bằng Parcelable.
- Sửa họ tên và nhận kết quả trả về bằng Activity Result API.
- Mở ứng dụng gọi điện, trang web và chia sẻ văn bản bằng Intent.
- NC2: truyền danh sách Contact bằng Parcelable.
- NC4: nhận văn bản chia sẻ từ ứng dụng khác.

## Cách chạy

1. Mở thư mục `A5_231A290036` bằng Android Studio.
2. Chờ Gradle Sync, chọn module `app`.
3. Chọn máy ảo hoặc điện thoại Android API 24 trở lên và bấm **Run**.

Project sử dụng Java + XML, Java 17 và compileSdk 35.
